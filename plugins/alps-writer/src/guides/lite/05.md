<section_guide number="5" title="Key Screens">
<purpose>Derive the minimum screen set needed to express the approved scenario, Features, and shared principles.</purpose>

<questions>
1. Which moments in the Primary User Scenario require a distinct screen or workspace?
2. What must the user see and do on each screen?
</questions>

<workflow>
Propose the screen inventory from Sections 3, 4, and 6 instead of asking the user to invent pages
from scratch. Every screen must reference one or more existing Feature IDs. Remove screens that do
not serve the approved scenario or Feature list. Include only visible states that apply.
</workflow>

<completion>Confirm the screen inventory, navigation, and visible states before saving.</completion>
</section_guide>
