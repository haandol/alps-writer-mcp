<section_guide number="1" title="Product Overview">
<purpose>Define the product in the language of the primary user and the change the PoC should make possible.</purpose>

<questions>
1. Who is the first user, and in what situation do they experience the problem?
2. What should they be able to do or decide differently after using the product?
</questions>

<workflow>
Use the project name as the initial Product Name candidate. Draft the one-line summary, problem,
solution direction, and expected user change from the user's answers. Do not add a second user
segment or a solution capability the user did not confirm.
</workflow>

<completion>Present one approval digest covering 1.1-1.6, then save each approved subsection separately.</completion>
</section_guide>
